# Three.js Interactive WebGL Journey 🌌

Interactive 3D graphics and WebGL experiments built with **Three.js**.  
This repository contains hands-on implementations covering core 3D concepts, shaders, animations, physics, and model loading.

---

## 🚀 Learning Modules & Experiments

| Section | Topic | Key Concepts |
| :---: | :--- | :--- |
| **05 ~ 07** | **Basics & Controls** | Transform objects, requestAnimationFrame loops, OrbitControls & Cameras |
| **08 ~ 11** | **Scene Essentials** | Fullscreen resizing, Geometry attributes, lil-gui debug UI, Textures & Mipmaps |
| **12 ~ 14** | **Materials & Text** | MeshStandardMaterial, Environment maps, 3D text typography, Production deploy |
| **15 ~ 17** | **Lighting & Shadows** | Directional/Point/Spot lights, Shadow maps, Haunted House scene composition |
| **18 ~ 20** | **Particles & FX** | Particle systems, Procedural Galaxy Generator, Scroll-triggered 3D animation |
| **21 ~ 23** | **Physics & Interaction** | Cannon.js physics simulation, GLTF/GLB 3D models import, Raycaster mouse picking |
| **25 ~ 26** | **Advanced Architecture** | Realistic PBR rendering, Code structuring for production 3D applications |

---

## 🛠️ Tech Stack

- **Core**: Three.js, WebGL, JavaScript (ES6+)
- **Tools**: Vite / Webpack, lil-gui, Cannon.js (Physics)
- **Assets**: Blender GLTF/GLB models, HDR environment maps

---

## 💻 Getting Started

```bash
# Navigate to any module
cd 19-galaxy-generator

# Install dependencies
npm install

# Start local dev server
npm run dev
```
